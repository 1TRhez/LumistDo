安装使用

  1. 点击上方「下载 Windows 版」，下载 LumistDo-Setup-v*.exe 安装包。
  2. 双击安装包，按向导一步步安装（仅当前用户安装，不需要管理员权限）。因软件没有购买代码签名证书，首次运行若提示“Windows 已保护你的电脑”，可点击「更多信息」→「仍要运行」。源码全部公开在 GitHub 仓库，可自行审查或从源码运行。
  3. 安装完成后可从开始菜单或桌面快捷方式启动。
  4. 任务数据保存在 %APPDATA%\LumistDo，重装、更新都不会丢失。
  5. 卸载走 Windows「设置 → 应用」或双击运行安装文件夹内的 unins000.exe，卸载时可选是否删除数据。

功能亮点

🪟 半透明悬浮桌面无边框窗口透出壁纸，任务与桌面融为一体，透明度可自由调节。
📦 一键安装标准安装向导，无需 Python 环境；数据与程序分离，更新、重装不丢数据。
📝 随手记、随手划点一下新建，双击就地改，点圆点就划掉；任务还能按住上下拖动排序。
🎨 主题预设深空 / 暖夜 / 毛玻璃 / 海洋 / 薰衣草 / 素白六套预设；想要别的颜色就点预设行最右边的「自定义配色」，单独调背景色与字体颜色。
📌 三态窗口层级图钉一键循环：普通层级 → 最上层 → 最底层，随手决定它压着谁。
缩略模式顶栏整块渐隐只留任务列表，鼠标贴顶才露出图标，点一下窗口也能临时唤回。
🫧 真·毛玻璃调用系统 DWM 把窗口背后的桌面内容真正模糊掉，不是单纯调透明度；不开毛玻璃时也只是同一张卡片的另一面。
🎛️ 自定义配色预设行最右边是自定义入口：单独挑背景色与字体颜色，改完即时生效；浅色主题自动换深色字。
⌨️ 可改快捷键层级 / 固定位置 / 缩略模式三组快捷键逐项自定义，默认注册成系统级热键，撞键自动让位，退格清空即不绑定。
🕘 历史任务完成与删除的任务进入历史记录，可随时恢复或彻底清除。
🌏 中英双语设置中一键切换中文 / English，重启即生效。
🛡️ 隐私优先无账号、无云端、无遥测、不联网，所有数据只保存在你自己的电脑上。
